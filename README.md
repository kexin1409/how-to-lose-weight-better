## 核心来源与口径

- **中国骨架**：《肥胖症诊疗指南（2024 年版）》——一次性列出 7 种医学减重膳食（限能量 / 轻断食 5+2 / 低碳 / 高蛋白 / 低脂 / 代餐 / 极低能量）与药物、手术指征 https://xhyxzz.pumch.cn/article/doi/10.12290/xhyxzz.2024-0918
- **药物证据**：STEP 1（司美格鲁肽 2.4 mg，68 周 −14.9% vs −2.4%）、SURMOUNT-1（替尔泊肽 15 mg，72 周 −20.9% vs −3.1%）、SURMOUNT-4（停药反弹约 14%）等大型随机试验；SELECT（司美降低主要心血管事件 20%）
- **手术证据**：ASMBS 2024 系统综述——手术 vs GLP-1 vs 生活方式，袖状胃 / 胃旁路 1 年减总体重约 29.5% / 31.9%，10 年维持约 25% https://asmbs.org/articles/bariatric-surgery-more-effective-and-durable-than-new-obesity-drugs-and-lifestyle-intervention
- **机制证据**：代谢适应（adaptive thermogenesis）、Biggest Loser 长期追踪、体重调定点与反弹研究

## 这本书讲什么

能量平衡这条硬道理、七种医学减重膳食怎么选，蛋白质和抗阻怎么守住肌肉、运动在减重里的真实位置，平台期与代谢适应、反弹怎么防，也讲 GLP-1、减重药物和减重手术的智商税清单。12 节 144 条，每条写明成本、收益、证据等级、风险与原始出处。
